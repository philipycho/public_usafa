# public_usafa

Public course materials and datasets for classes taught by Lt Col Cho at the
U.S. Air Force Academy.

**Site:** https://philipycho.github.io/public_usafa/

Materials are organized by course into folders named `<course number>_<semester><year>`
(e.g. `DS220_Fall2026`). The homepage lists everything currently posted, along
with the date each item was posted and its type (webpage, slides, dataset, etc.).

## Courses

- **DS220** — Data-Driven Statistics with AI (Fall 2026)
- **OR476** — Sports Analytics (Fall 2026)

Questions? Contact Lt Col Cho at philip.cho@afacademy.af.edu.
